# Queues-Stacks-LinkedLists

DSA Assignment 2 — C++ implementations covering Queues, Stacks, and Linked Lists from scratch. No STL headers used.

---

## Tasks

| File | Topic | Description |
|------|-------|-------------|
| task1.cpp | Queue | Reverse a queue using only queue operations |
| task2.cpp | Queue | Remove duplicates while preserving order |
| task3.cpp | Linked List | Sort a singly linked list using bubble sort |
| task4.cpp | Stack + Queue | Evaluate a prefix expression |
| task5.cpp | Linked List | Lottery ticket checker (palindrome + digit sum) |
| task6.cpp | Queue | Distribute passengers into 4 lanes by passport number |

---

## Rules followed

- No `#include <stack>`, `#include <vector>`, `strlen`, `strcpy` or any STL
- All data structures built manually using arrays and linked list nodes
- No recursion where restricted

---

## How to run

```bash
g++ task1.cpp -o task1 && ./task1
g++ task2.cpp -o task2 && ./task2
g++ task3.cpp -o task3 && ./task3
g++ task4.cpp -o task4 && ./task4
g++ task5.cpp -o task5 && ./task5
g++ task6.cpp -o task6 && ./task6
```
